# خطة الأطلس التشريحي ثلاثي الأبعاد (Z-Anatomy + BodyParts3D)

> حالة المستند: خطة معمارية (لم تُنفّذ بعد). الهدف: ترقية خريطة الجسم من 2D تفاعلية إلى عرض تشريحي 3D، مع الحفاظ على الأداء والخصوصية.

## 1) الوضع الحالي

- التطبيق يعرض خريطة جسم تفاعلية عبر `react-native-body-parts-anatomy` (317 قطعة، 23 مجموعة عضلية، ذكر/أنثى × أمام/خلف).
- على الويب: `WebBodySilhouette.tsx` يعرض SVG تفاعلي (onPress + تكبير/تحريك).
- على الجوال: `BodySilhouette` من حزمة الأطلس.

## 2) لماذا 3D؟

- فهم أعمق للعلاقة بين العضلات والمناطق.
- تمييز أفضل للطبقات (سطحية/عميقة).
- تجربة أكثر احترافًا للأغراض التعليمية.

## 3) المصادر المقترحة

| المصدر | المحتوى | الترخيص | ملاحظة |
|---|---|---|---|
| **Z-Anatomy** | أطلس كامل مبني على Blender، نماذج GLB | CC BY-SA | الأفضل للبداية: مفتوح ومكتمل |
| **BodyParts3D** | نماذج عضوية دقيقة (FMA-coded) | CC BY-SA 2.1 JP | دقيق لكن يحتاج معالجة |

**شرط الإسناد:** يجب ذكر المصدر والترخيص (CC BY-SA) داخل التطبيق وفي صفحة «حول».

## 4) المتطلبات التقنية

- `expo-gl` — سياق WebGL داخل React Native.
- `three` + `@react-three/fiber` (نسخة متوافقة مع RN) أو `expo-three`.
- `expo-asset` لتحميل ملفات `.glb`.
- ضغط النماذج (Draco/meshopt) لتقليل الحجم.

## 5) المعمارية المقترحة

```
components/anatomy3d/
  Anatomy3DViewer.tsx      # غلاف العرض (GL + مشهد)
  MuscleMesh.tsx           # شبكة عضلة واحدة + تلوين + اختيار
  useAnatomyModel.ts       # تحميل النموذج + الفهرسة
  mapping3d.json           # ربط أسماء شبكات GLB بمجموعات التطبيق
```

- ربط كل شبكة 3D بمعرّف مجموعة عضلية موجود (`lower-back`, `quadriceps` ...) لإعادة استخدام منطق المكتبة الطبية.
- عند اختيار عضلة، تُلوّن وتُعرض بطاقة `ConditionInfoCard` المرتبطة.

## 6) الأداء

- تحميل كسول (lazy) للنموذج عند فتح الشاشة فقط.
- مستويات تفصيل (LOD): نسخة خفيفة للمعاينة، كاملة عند التكبير.
- تعطيل 3D على الأجهزة الضعيفة مع الرجوع للخريطة 2D.

## 7) خطة التنفيذ المقترحة

1. إعداد `expo-gl` + `three` في مشروع تجريبي.
2. تحويل نموذج Z-Anatomy إلى GLB مضغوط.
3. بناء `Anatomy3DViewer` + اختيار العضلات.
4. ربط الاختيار بالمكتبة الطبية (`services/medical`).
5. اختبار الأداء على جهاز متوسط، ثم الإطلاق التدريجي.

## 8) البديل الأخف (بدون 3D حقيقي)

إذا كان 3D مكلفًا: عرض **طبقات SVG** متعددة (سطحية/عميقة) مع إمكانية التبديل، وهو أسرع تنفيذًا وأخف على الأجهزة، ويحقّق جزءًا كبيرًا من القيمة التعليمية.
