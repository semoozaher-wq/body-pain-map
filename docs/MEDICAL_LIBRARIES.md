# المكتبات الطبية في BodyMap Pain — الكتالوج الكامل

> الهدف: تحويل التطبيق من مجرد «تحديد نقطة ألم» إلى أداة تثقيف صحي حقيقية، عبر دمج مصادر طبية مفتوحة وموثوقة، مع الحفاظ على مبدأ **الخصوصية أولًا** (بيانات محلية، بلا حسابات، بلا سحابة).

هذا المستند يوثّق الطبقات الخمس التي طُلبت، وحالة تنفيذ كل منها داخل التطبيق.

---

## أولاً — البيانات المحلية (Offline): تعمل بدون إنترنت

هذه الطبقة مدمجة داخل التطبيق، ولا تحتاج أي شبكة، وهي الأساس الذي يمنح قيمة طبية فورية للمستخدم.

| المصدر | الوصف | الترخيص | الحالة |
|---|---|---|---|
| **Disease Ontology (DOID)** | أنطولوجيا الأمراض، أكواد `DOID` مرجعية | CC0 (ملكية عامة) | ✅ مُدمج |
| **Human Phenotype Ontology (HPO)** | أنطولوجيا الأعراض، أكواد `HP:xxxxxxx` | مفتوح (CC BY 4.0) | ✅ مُدمج |
| **ICD-10-CM** | تصنيف الأمراض الدولي | ملكية عامة (WHO/CDC) | ✅ مُدمج |
| **MedlinePlus** | محتوى تثقيفي للمرضى | حكومي أمريكي (يُسمح بالربط) | ✅ مُدمج (روابط) |

**الملفات المُنشأة:**

- `data/medical/diseases.json` — 23 حالة مرضية شائعة مرتبطة بمجموعات العضلات ومناطق الجسم، مع أسماء وملخصات وعلامات خطر ثلاثية اللغة (عربي/إنجليزي/فرنسي)، وأكواد `DOID` و`ICD-10`، وروابط MedlinePlus.
- `data/medical/symptoms.json` — 28 عرضًا مرجعيًا بأكواد `HPO`، مع وصف ثلاثي اللغة وربط بمناطق الجسم وتحديد ما إذا كان «علامة خطر».
- `data/medical/sources.json` — سجل المصادر وحالة ترخيص كل مصدر.
- `services/medical/diseaseLibrary.ts` — محرّك البحث المحلي (حسب مجموعة العضلات، المنطقة، العرض، أو بحث نصي).
- `hooks/useMedicalLibrary.ts` — خطّافات React للوصول للمكتبة.

**كيف يستفيد المستخدم؟** يختار منطقة الجسم، فيرى قائمة الأمراض المحتملة المرتبطة بها، مع أعراضها وعلامات الخطر التي تستوجب مراجعة الطبيب، وروابط لمصادر موثوقة — كل ذلك بدون إنترنت.

## ثانياً — واجهات برمجية حيّة (Live APIs): محتوى محدّث عند الحاجة

| المصدر | الوصف | مفتاح؟ | الحالة |
|---|---|---|---|
| **MedlinePlus Connect** | ربط أكواد ICD-10/SNOMED بمحتوى NLM | لا | ✅ مُدمج |
| **RxNorm / RxNav** | توحيد أسماء الأدوية + التفاعلات | لا | ✅ مُدمج |
| **openFDA** | ملصقات الأدوية + الأحداث الجانبية | لا | ✅ مُدمج |
| **ICD-11 API (WHO)** | تصنيف دولي حديث | نعم (تسجيل مجاني) | ⏳ موثّق، غير مُفعّل |
| **Open Targets** | ربط الأمراض بالجينات والأهداف الدوائية | لا | ⏳ موثّق، بحث متقدم |

**الملفات المُنشأة:**

- `services/medical/rxNorm.ts` — بحث الأدوية، الجلب بـ RxCUI، والتفاعلات الدوائية.
- `services/medical/openFda.ts` — ملصقات الأدوية (دواعي، تحذيرات، جرعة، موانع) + أكثر الأحداث الجانبية.
- `services/medical/medlinePlusConnect.ts` — ربط الأكواد بمحتوى MedlinePlus.
- `services/medical/index.ts` — تجميع الخدمات + إعدادات `MEDICAL_SETTINGS`.
- `hooks/useDrugLookup.ts` — خطّاف البحث عن الأدوية مع حالات التحميل والخطأ.

**ملاحظة تصميمية:** كل نداءات الشبكة **اختيارية** وتفشل بهدوء (`fail-soft`) إذا لا يوجد اتصال، فتبقى الطبقة المحلية تعمل دائمًا.

## خامساً — التصنيفات والتراخيص (تحذيرات مهمة)

| التصنيف | الترخيص | القرار |
|---|---|---|
| **SNOMED CT** | يتطلب ترخيصًا خارج الدول الأعضاء | ⚠️ غير مُضمّن |
| **LOINC** | مجاني مع الإسناد | ✅ مسموح |
| **CPT (AMA)** | مدفوع/مرخّص | ⚠️ غير مُضمّن |
| **MedlinePlus** | يُسمح بالربط والعرض، لا بنسخ الصفحات | ✅ روابط فقط |

**قاعدة ذهبية:** لا نُضمّن أي محتوى يتطلب ترخيصًا مدفوعًا (CPT، SNOMED خارج النطاق)، ونكتفي بالربط الخارجي للمحتوى الحكومي المجاني.

## البنية العامة للطبقة الطبية

```
data/medical/
  diseases.json          # 23 حالة (DOID + ICD-10 + HPO + MedlinePlus)
  symptoms.json          # 32 عرضًا (HPO)
  sources.json           # سجل المصادر والتراخيص

services/medical/

  openFda.ts             # ملصقات وأحداث جانبية (openFDA)
  medlinePlusConnect.ts  # ربط الأكواد بمحتوى NLM
  index.ts               # barrel + MEDICAL_SETTINGS

hooks/
  useMedicalLibrary.ts   # خطّافات المكتبة المحلية
  useDrugLookup.ts       # خطّاف البحث عن الأدوية

components/
  MedicalLibraryPanel.tsx  # تصفّح الأمراض حسب المنطقة
  ConditionInfoCard.tsx    # بطاقة حالة + أعراض + علامات خطر
  DrugLookupPanel.tsx      # بحث الأدوية + الملصق
```

## مبدأ السلامة الطبية

كل محتوى الطبقة الطبية **تعليمي عام فقط**، ولا يقدّم تشخيصًا أو علاجًا. الأكواد (DOID/ICD-10/HPO) للمطابقة المرجعية فقط. التطبيق يعرض دائمًا إخلاء المسؤولية، ويوجّه المستخدم لمراجعة طبيب أو صيدلي مؤهل، ويميّز بوضوح «علامات الخطر» التي تستوجب رعاية عاجلة.
