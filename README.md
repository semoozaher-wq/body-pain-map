# BodyMap Pain

تطبيق تعليمي مبني بـ **React Native + Expo** يساعد المستخدم على اختيار موضع الألم، تسجيل وصفه، ومراجعة إرشاد عام مع تنبيهات سلامة واضحة. التطبيق ليس أداة تشخيص ولا بديلًا عن الطبيب أو خدمات الطوارئ.

## الميزات الحالية

يحتوي التطبيق على خريطة طبية تفاعلية تضم **317 جزءًا و23 مجموعة**، مع البحث بالرقم أو الاسم وتبديل الجنس والواجهة الأمامية أو الخلفية. توجد أيضًا خريطة عضلية SVG بصرية مستقلة تضم 176 مسارًا قابلًا للضغط والتلوين. لا تُستخدم مسارات SVG الجديدة لاستدعاء بيانات طبية تلقائيًا لأن الملف الأصلي لا يحتوي أسماء عضلات دلالية موثقة.

يمكن تسجيل شدة الألم من 0 إلى 10، ونوعه، ومدته، والملاحظات، وعلامات الإنذار. تظهر النصائح التفاعلية وبطاقة الإسعاف التعليمية والتقرير القابل للطباعة والمساعد المحلي التجريبي وتحليل الصورة التجريبي في شاشة النتائج. لا ترسل هذه الميزات صورًا أو سجلًا إلى خادم.

يتضمن التطبيق سجلًا محليًا محفوظًا على الجهاز، ورسمًا وصفيًا لتطور الشدة، وتذكيرًا محليًا. يمكن تغيير اللغة من شريط الواجهة بين العربية والإنجليزية والفرنسية، ويمكن تبديل الوضع الداكن وحفظ الاختيار محليًا.

## التشغيل والفحص

```bash
npm install
npm run web
```

لبناء نسخة الويب:

```bash
npm run build:web
```

لفحص TypeScript:

```bash
npx tsc --noEmit
```

لفحص بيانات التشريح:

```bash
npm run validate:pain-map -- data/anatomyPainMap.json
```

## بنية مهمة

| المسار | الغرض |
|---|---|
| `App.tsx` و`MainApp.tsx` | نقطة الدخول وإدارة الشاشات والحالة المحلية |
| `screens/BodyPickerScreen.tsx` | اختيار موضع الألم والخريطتان البصرية والطبية |
| `components/WebBodySilhouette.tsx` | خريطة 317 التفاعلية للويب |
| `components/MuscleSvgMap.tsx` | مكوّن SVG العضلي البصري |
| `assets/anatomy/muscles-front-back.svg` | أصل SVG المرخص |

| `hooks/useLanguage.ts` | اللغة المحفوظة محليًا |
| `hooks/useTheme.tsx` | الثيم المحفوظ محليًا |

| `.github/workflows/build.yml` | فحص البيانات وTypeScript وبناء الويب |

## الخصوصية والسلامة

يحفظ التطبيق سجل الألم والتفضيلات محليًا باستخدام AsyncStorage. لا توجد خدمة خلفية في النسخة الحالية. لا تضع مفاتيح API أو بيانات مرضى في المستودع. يوجد `.env.example` كمرجع غير سري فقط.

المحتوى الطبي إرشادي وقالب أولي ويحتاج إلى مراجعة طبيب مختص ومراجعة قانونية قبل استخدام التطبيق تجاريًا أو الاعتماد عليه في قرارات علاجية. اطلب المساعدة العاجلة عند ألم شديد أو مفاجئ أو ضيق نفس أو إغماء أو ضعف مفاجئ أو إصابة قوية.
