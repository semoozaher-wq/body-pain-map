# BodyMap Pain

تطبيق موبايل عربي مبني بـ **React Native + Expo** يساعد المستخدم على تحديد مكان الألم، وصفه، وقراءة الأسباب الشائعة والتنبيهات العامة والتوصية الأولية بالتخصص المناسب.

> **تنبيه طبي:** التطبيق أداة تعليمية وفحص مبدئي فقط، وليس بديلًا عن الطبيب ولا يقدم تشخيصًا. عند وجود ألم شديد أو مفاجئ، أو ضيق نفس، أو إغماء، اتصل بالإسعاف فورًا.

## ما الذي يعمل في النسخة الأولية؟

- شاشة موافقة وتحذير طبي واضح.
- اختيار الجنس واتجاه الجسم.
- اختيار منطقة الألم من واجهة عربية تفاعلية مبسطة.
- تسجيل شدة الألم من 0 إلى 10، ونوعه، ومدة ظهوره.
- عرض الأسباب الشائعة المحتملة والتحذيرات والتوصية العامة.
- سجل للفحوصات داخل جلسة التطبيق الحالية.
- قاعدة بيانات محلية قابلة للتوسعة في `data/painMap.json`.
- تصميم RTL بألوان هادئة وملاحظات عدم التشخيص في النتائج.

## التشغيل محليًا

```bash
npm install
npx expo start
```

بعدها يمكن فتح التطبيق من خلال Expo Go على الهاتف، أو تشغيله عبر المحاكي:

```bash
npm run android
npm run ios
npm run web
```

## هيكل المشروع

- `App.tsx`: التنقل والتدفق الأساسي لكل الشاشات.
- `data/painMap.json`: بيانات المناطق والأسباب والتحذيرات والتوصيات.
- `assets/`: أصول Expo الافتراضية.

## الخطوات التالية المقترحة

1. استبدال واجهة المناطق المبسطة برسمة تشريحية مرخصة ومراجعة توافقها مع الجنس والاتجاه.
2. إضافة تخزين محلي دائم ومشفر للتاريخ بعد تحديد سياسة الخصوصية.
3. توسيع المناطق والبيانات ومراجعتها من طبيب مختص قبل النشر.
4. إضافة اختبارات للتدفق والتحذيرات ومراجعة الوصولية ودعم أحجام الشاشات.
5. تجهيز إعدادات النشر إلى Google Play وApp Store بعد المراجعة القانونية والطبية.
