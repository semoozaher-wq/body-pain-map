# BodyMap Pain

تطبيق تعليمي مبني بـ **React Native + Expo** يساعد المستخدم على تسجيل الألم وفهم سجله الشخصي. لا يقدم التطبيق تشخيصًا أو علاجًا أو خدمة طوارئ، ولا يحل محل الطبيب.

## المزايا

- خريطة تشريحية تفاعلية تضم **317 جزءًا و23 مجموعة**، مع العرض الأمامي والخلفي، اختيار الجنس، والبحث بالاسم أو الرقم.
- سجل نوبة الألم: المنطقة والوقت تلقائيًا، الشدة، نوع/مدة الألم، أعراض، علامات إنذار، ملاحظات، دواء/علاج، محفزات، نوم/نشاط، وتقييم اختياري للشدة بعد الرعاية.
- سجل محلي ولوحة اتجاهات ورسوم وصفية لفترات 7 و30 و90 يومًا، مع تقرير للطبيب قابل للطباعة/PDF يشمل الرسم والدواء والأعراض وعلامات الإنذار ومقارنة قبل/بعد.
- تقرير قابل للطباعة أو PDF على iOS/Android، ونسخة JSON احتياطية مع استيراد ودمج محلي للسجلات.
- تذكير محلي اختياري: إشعار نظام على الهاتف بعد منح الإذن، وتذكير محلي في الويب.
- أطلس أمامي وخلفي للعضلات وصورة أعضاء داخلية للذكر والأنثى (مع الرحم والمبيضين)، ومؤشرات تفاعلية تم ضبطها على مواضع الصور؛ الصور إيضاحية وليست سريرية.
- العربية والإنجليزية والفرنسية، مع سمة فاتحة وداكنة.

لا تستخدم النسخة حسابًا أو مزامنة سحابية أو تحليلات عن بُعد. التصدير والاستيراد يدويان بطلب المستخدم. ملفات النسخ الاحتياطية تحتوي بيانات صحية شخصية، فاحفظها في مكان آمن. التخزين المحلي لا يعني تلقائيًا أن البيانات مشفّرة.

## نقاط الضغط والعناية الذاتية والأعضاء الداخلية

- أُضيف عرض أعضاء SVG مبسّط مرسوم داخل التطبيق، مرتبط بنقاط الأعضاء الموجودة ومجموعات/أجزاء الخريطة التشريحية. مواضعه تقريبية وتعليمية، ولا يستنتج العضو المصاب من مكان الألم.
- أُضيفت عينة أولية من **4 نقاط ضغط** موثقة (LI4 وPC6 وGB20 وSP6) مع موضع تقريبي، رسم توضيحي، طريقة لمس لطيفة، مستوى الدليل، التحذيرات وروابط المصادر. ليست قائمة بكل النقاط؛ تسمية WHO تتضمن 361 نقطة تقليدية.
- أُضيفت **6 إرشادات مساعدة غير دوائية** لألم/شد العضلات، الظهر، الرقبة، الدورة، الصداع، والغثيان، مع موانع وتنبيهات لفئات خاصة وروابط NHS/NCCIH.
- تظهر إخلاءات مسؤولية واضحة بالعربية والإنجليزية والفرنسية. لا توجد توصية بإبر أو جرعات أعشاب/مكملات، ومحتوى الرعاية يحتاج مراجعة مختصين قبل الإطلاق الطبي.
- ملف مصادر المحتوى: `MEDICAL_REFERENCES.md`.

## التشغيل والتحقق

```bash
npm ci
npm run typecheck
npm run validate:pain-map
npm run validate:clinical-guides
npm run build:web
npm run test:e2e
npm run build:ios:bundle
npm run build:android:bundle
npm run web
```

تغييرات الإشعارات والطباعة والمشاركة تتطلب إعادة بناء نسخة iOS/Android عبر EAS Build أو إعدادات Expo الأصلية.

## تجربة الشاشة والرسوم التشريحية

- تعرض الصفحة الرئيسية ملخصًا وصفيًا لآخر 7 أيام، تسجيلًا سريعًا قابلًا للفتح عند الحاجة، وزرًا واضحًا لخريطة الجسم مع شريط تنقل سفلي.
- أضيفت رسوم أمامية وخلفية للعضلات ورسمة للأعضاء الداخلية. المؤشرات فوق الصور تقريبية وعلى مستوى المناطق؛ استخدم خريطة SVG ذات **317 جزءًا** للتحديد الأدق. الصور مولّدة للتطبيق، منمّقة وتعليمية وليست مرجعًا سريريًا أو تشخيصيًا.
- عند ظهور علامة إنذار مختارة، يفصل التطبيق ذلك عن شدة الألم المسجّلة العالية وحدها؛ كما يسجل العلامات في تقرير الزيارة.
- CI يستخدم Node 22، ويشغّل اختبارات الفرز والواجهة، وفحوصات بيانات التشريح والإرشادات، وبناء الويب وتصدير حزم JavaScript الموجهة لـiOS/Android.
- إعداد EAS مضاف للنسخ الداخلية وAndroid App Bundle. اجتازت حزم JavaScript الخاصة بـiOS/Android التصدير؛ لم يُبنَ IPA/APK ولم يُجرَ اختبار على أجهزة فعلية بعد. يلزم ذلك، ومراجعة طبيب/خصوصية/متاجر، قبل النشر.

## تنبيه طبي

المحتوى تعليمي وصفي فقط. غياب تنبيه من التطبيق لا يثبت أن الحالة آمنة. الصور والخرائط لا تقدم تحديدًا سريريًا؛ بيانات الـ317 جزءًا ما زالت تحتاج تدقيقًا طبيًا فرديًا قبل أي إطلاق تجاري أو ادعاء طبي. يلزم طبيب مؤهل لمراجعة قواعد الفرز والتنبيهات والمحتوى؛ فنجاح البناء والاختبارات الآلية لا يساوي اعتمادًا طبيًا.
