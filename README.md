# BodyMap Pain

تطبيق عربي مبني بـ **React Native + Expo** يساعد المستخدم على تحديد مكان الألم، وصفه، ومراجعة إرشاد عام مع تنبيهات سلامة واضحة. التطبيق تعليمي وفحص مبدئي فقط، وليس بديلًا عن الطبيب أو خدمات الطوارئ.

## الميزات الحالية

يحتوي التطبيق على خريطة تشريحية تفاعلية تضم 317 جزءًا و23 مجموعة، مع البحث برقم الجزء أو اسمه، وتبديل الجنس والواجهة الأمامية أو الخلفية. يمكن للمستخدم تسجيل شدة الألم من 0 إلى 10، ونوعه، ومدة ظهوره، وإضافة ملاحظات اختيارية.

أضيف فحص علامات إنذار مبكر قبل عرض الإرشاد، ويظهر تنبيه عاجل عند اختيار ضيق النفس أو الإغماء أو الضعف المفاجئ أو الإصابة القوية، وكذلك عند شدة 8/10 فأكثر. هذه الإشارات لا تشخّص الحالة، لكنها تساعد على عدم تجاهل الأعراض الخطيرة.

يحفظ التطبيق السجل على الجهاز فقط. تعرض شاشة السجل عدد الفحوصات ومتوسط الشدة وعدد التنبيهات، وتتيح حذف السجل بالكامل بعد تأكيد المستخدم. يمكن مشاركة ملخص الفحص باستخدام وظائف المشاركة في الجهاز.

## التشغيل محليًا

```bash
npm install
npm run web
```

ولإنشاء نسخة الويب:

```bash
npm run build:web
```

لفحص بيانات التشريح:

```bash
npm run validate:pain-map -- data/anatomyPainMap.json
```

## الخصوصية والتكاملات

لا تحتاج النسخة الحالية إلى API خارجي، ولا ترسل سجل الألم إلى خادم. يوجد `.env.example` كمرجع فقط، ويجب عدم وضع أسرار أو مفاتيح داخل تطبيق الويب. عند إضافة تكامل طبي مستقبلاً، استخدم خادمًا وسيطًا وراجع `PRIVACY.md` و`SECURITY.md` قبل النشر.

## مراجعة طبية مهمة

النصوص الطبية في `data/anatomyPainMap.json` إرشادية ومولدة كقالب أولي، وتحتاج إلى مراجعة طبيب مختص ومراجعة قانونية قبل استخدامها تجاريًا أو الاعتماد عليها في قرارات علاجية. لا تضف محتوى طبيًا جديدًا دون مصدر ومراجعة مختص.

## الملفات المهمة

| الملف | الغرض |
|---|---|
| `App.tsx` | التدفق الرئيسي والشاشات والميزات المحلية |
| `components/WebBodySilhouette.tsx` | الخريطة التشريحية التفاعلية للويب |
| `data/anatomyPainMap.json` | بيانات 317 جزءًا تشريحيًا |
| `PRIVACY.md` | سياسة الخصوصية والتخزين المحلي |
| `TERMS.md` | شروط الاستخدام والإخلاء الطبي |
| `SECURITY.md` | إرشادات الأمان والإبلاغ عن الثغرات |
| `.github/workflows/build.yml` | بناء وفحص تلقائي عند الدفع أو Pull Request |
