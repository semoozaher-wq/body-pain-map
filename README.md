# BodyMap Pain

تطبيق تعليمي مبني بـ **React Native + Expo** يساعد المستخدم على تسجيل الألم وفهم سجله الشخصي. لا يقدم التطبيق تشخيصًا أو علاجًا أو خدمة طوارئ، ولا يحل محل الطبيب.

## المزايا

- خريطة تشريحية تفاعلية تضم **317 جزءًا و23 مجموعة**، مع العرض الأمامي والخلفي، اختيار الجنس، والبحث بالاسم أو الرقم.
- تسجيل سريع للألم أو متابعة كاملة تشمل الشدة والنوع والمدة والملاحظات، ودواء/علاج استخدمه المستخدم، ومحفزًا محتملًا لاحظه، وساعات النوم والنشاط.
- سجل محلي ولوحة اتجاهات وصفية لفترات 7 و30 و90 يومًا. لا تستنتج اللوحة سببًا ولا تقدم تشخيصًا.
- تقرير قابل للطباعة أو PDF على iOS/Android، ونسخة JSON احتياطية مع استيراد ودمج محلي للسجلات.
- تذكير محلي اختياري: إشعار نظام على الهاتف بعد منح الإذن، وتذكير محلي في الويب.
- العربية والإنجليزية والفرنسية، مع سمة فاتحة وداكنة.

لا تستخدم النسخة حسابًا أو مزامنة سحابية أو تحليلات عن بُعد. التصدير والاستيراد يدويان بطلب المستخدم. ملفات النسخ الاحتياطية تحتوي بيانات صحية شخصية، فاحفظها في مكان آمن. التخزين المحلي لا يعني تلقائيًا أن البيانات مشفّرة.

## التشغيل والتحقق

```bash
npm ci
npm run typecheck
npm run validate:pain-map
npm run build:web
npm run web
```

تغييرات الإشعارات والطباعة والمشاركة تتطلب إعادة بناء نسخة iOS/Android عبر EAS Build أو إعدادات Expo الأصلية.

## تنبيه طبي

المحتوى تعليمي وصفي فقط. غياب تنبيه من التطبيق لا يثبت أن الحالة آمنة. راجع النصوص وقواعد السلامة مع مختصين قبل أي إطلاق تجاري أو ادعاء طبي.
